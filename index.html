How do I get started with Orix?

Install Orix, run the CLI, choose your stack, and let Orix generate your project structure automatically.

What are the system requirements?

Orix requires Python 3.11+ for CLI support and Node.js 18+ for frontend stacks such as React and Next.js.

Is Orix open source?

Yes. Orix is designed to help you bootstrap projects quickly with reusable and open starter templates.

Can I customize the generated apps?

Absolutely. Orix generates full source code for each project so you can modify layouts, APIs, auth, and deployment settings.

How do I change the project settings?

Update the generated project files and environment variables to match your service configuration, database, and deployment targets.

Can I add a database?

Yes. Orix supports SQLite and PostgreSQL for backend projects, and includes Docker-ready database configuration where needed.

Can I use my own hosting?

Yes. Orix projects are standard web apps, so you can deploy them to any cloud provider or static host compatible with the selected stack.

Where can I find help?

Use the Orix docs, GitHub issue tracker, and community resources to ask questions and share feedback.

How do I report bugs?

Report bugs through the GitHub repository so the team can track and fix issues with Orix or the generated templates.

Can I contribute to Orix?

Yes. Contributions are welcome through GitHub, including feature requests, bug fixes, and documentation improvements.
