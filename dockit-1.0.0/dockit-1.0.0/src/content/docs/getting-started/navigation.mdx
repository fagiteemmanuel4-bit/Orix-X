# Welcome to Orix

Orix is a developer-friendly scaffolding toolkit that helps you create modern web and mobile apps quickly. With support for Django, FastAPI, Next.js, React, and Flutter, Orix gives you the foundation to ship real products faster.

## What Makes Orix Special?

### 🚀 **Productive by default**

Orix generates fully wired projects so you can focus on features instead of boilerplate.

### 📱 **Mobile and web ready**

Use Orix for web and mobile stacks, with clean structure for responsive apps and Flutter mobile builds.

### 🌙 **Modern tooling**

Orix is built around modern frameworks, developer tooling, and deploy-ready configuration.

### 🔍 **Searchable docs**

This documentation helps you find setup guides, framework references, and deployment notes quickly.

### ♿ **Developer-friendly**

Orix documentation is built to be clear, practical, and easy to follow for new projects.

## Who Is Orix For?

Orix is ideal for:

- **Developers launching new apps** — build production-ready scaffolding fast
- **Startup teams** — move from idea to MVP without setup overhead
- **Product designers** — create consistent starter apps across stacks
- **Educators** — teach full-stack app structure and deployment
- **Prototype builders** — iterate quickly with reusable templates

## Technology Stack

Orix supports modern frameworks and tools:

### Core Frameworks

- **Django** — API + auth-ready backend
- **FastAPI** — async Python services and REST APIs
- **Next.js** — React with Tailwind and App Router
- **React** — Vite-powered SPA projects
- **Flutter** — cross-platform mobile apps

### Styling & Tools

- **Tailwind CSS** — fast utility styling
- **Docker** — containerized development and deployment support
- **TypeScript** — optional typed frontend code
- **Python** — backend scripting and CLI support

### Content & Deployment

- **Markdown docs** — simple docs support
- **GitHub-friendly** — version control ready
- **CI/CD ready** — use generated Docker and service files
